**Joy records his own voice** — TTS was rejected (only the old robotic SAPI David/Zira exist on this
box) and he said so himself. `docs/video-script.md` is written for that: 10 lines, by **tone** not
timecode, with the stressed word bolded in each, because he records without watching the picture.
He leaves a ~2s gap between lines.

`scratchpad/browser/video/mux-voice.mjs` then cuts one continuous take on the **nine longest pauses**
(not on true silence, so room noise is fine), places each line at its cue, cascades anything that
runs long so lines never overlap, applies highpass + light denoise + levelling, and muxes.
⚠️ Its `CUES` array is measured from the caption log and must be rebuilt if the picture is re-recorded
(`record-slow.mjs` prints `CAP <seconds> "<text>"`). Takes so far: 2:07, 1:31, 1:55, 1:54.
